A tiny Python program that writes one line about a quiet, earned moment of pride to /output/entry.txt for make.fun's One Line of Earned Pride bounty. Top 10 share the $5 prize.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
